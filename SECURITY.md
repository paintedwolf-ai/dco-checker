# Security reporting

Report vulnerabilities through this repository's GitHub private vulnerability
reporting when enabled. If unavailable, use the security contact in the
[Painted Wolf AI organization](https://github.com/paintedwolf-ai) profile to arrange
private disclosure. Do not publish tokens, confidential commit contents, or a live
bypass recipe in a public issue. Ordinary policy and reliability defects can use
GitHub issues.

Maintainers assess affected release SHAs and consumers, reproduce the issue,
prepare a reviewed fix, qualify the replacement, and coordinate pin upgrades.
For an active certification bypass, stop affected merges or restore a reviewed
safe SHA, preserve logs, and disclose scope and remediation in release notes.
Rotate any exposed credentials. This project does not promise a response SLA.
Only releases explicitly listed as supported in release notes receive maintenance.

The [security model](docs/security-model.md) explains trusted writers, workflow
protection, and required-check app binding limits.
